\doxysubsection{Detailed Description}
{\ttfamily sq\+\_\+compilebuffer}関数がメモリバッファからソースコードを読み込む際に使用する状態を保持する構造体。 

この構造体は、{\ttfamily sq\+\_\+compilebuffer} 関数が {\ttfamily sq\+\_\+compile} と連携する際に、メモリ上のソースコードバッファをファイルのように見せかけるために使われます。 {\ttfamily sq\+\_\+compile} は {\ttfamily SQLEXREADFUNC} 型の読み込み関数を要求するため、{\ttfamily buf\+\_\+lexfeed} 関数がこの構造体を {\ttfamily SQUser\+Pointer} として受け取り、バッファからの文字の読み進め状態を管理します。
